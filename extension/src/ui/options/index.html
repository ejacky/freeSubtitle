freeSubtitle 设置

字幕翻译服务、语音识别、本地模型与隐私

字幕与输出

默认双语：原文小字在上，中文大字在下。

翻译服务

按顺序尝试；失败自动切下一条。OpenCode Go 需要 API Key，并发送 x-opencode-session 请求头。

提示：OpenCode Go 官方定位是编码代理，非编码流量可能被限流；建议保留本地 Ollama 作为兜底。 未填 Key 的云端服务会被自动跳过。

语音识别（无字幕视频）

本地 whisper.cpp 是默认方案；配置 Groq/OpenAI 后可切云端。

本地模型

本机无独显，本地模型只作为兜底；建议 4 线程，避免 8 线程争抢。本地 Ollama/Whisper 的地址与模型以本区块为准。

本地 ASR 启动：
cd local-asr
./setup.sh          # 首次：构建 whisper.cpp + 下载 base 模型
node server.mjs     # 127.0.0.1:8787

Ollama：
ollama pull qwen2.5:3b-instruct
# 若扩展连接被拒，重启 Ollama 时设置：
OLLAMA_ORIGINS='chrome-extension://*' ollama serve

内容审核与降级

云端拒绝敏感内容时，自动切到本地模型；不会自动删改原意。

隐私与缓存

API Key 只保存在本机；音频仅在音频模式下发送到你选择的 ASR 服务。

关于

freeSubtitle 0.1.2 · 字幕轨优先，音频识别兜底。受 DRM 保护的视频可能无法捕获音频； 本扩展不提供任何绕过能力。

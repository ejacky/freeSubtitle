# 隐私说明（草案）

freeSubtitle 是一个本地运行的浏览器扩展，用于把网页视频的外语字幕/语音翻译成中文。

## 处理的数据

- **字幕文本**：仅在启用翻译时读取当前视频的字幕轨；发送给你配置的翻译服务。
- **音频**：仅在没有字幕且启用音频兜底时，捕获当前标签页音频并发送给你配置的 ASR 服务。音频不落盘。
- **设置与密钥**：保存在本机 `chrome.storage.local`；不同步、不导出、不上传。
- **翻译缓存**：保存在本机 IndexedDB，用于减少重复请求；可在设置中清空。

## 数据发送对象

- 你配置的翻译/ASR 服务（例如 OpenCode Go、Groq、OpenAI、本地 Ollama、本地 whisper.cpp）。
- 扩展本身不收集、不出售、不分析用户数据；不包含 analytics/广告/远程代码。
- 本地模式下（本地 ASR + 本地 Ollama），音频和文本不离开本机。

## 保留与安全

- API Key 仅扩展后台可见；内容脚本无法读取。
- 诊断日志默认不记录字幕正文；可在设置中显式开启。
- 云端服务的保留期/训练策略由对应服务商决定，请阅读其条款。
- 受 DRM 保护的视频可能无法捕获音频；扩展不提供绕过能力。

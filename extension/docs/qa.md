# QA 清单

## 加载与构建

- [ ] `npm run typecheck` 无错误
- [ ] `npm test` 全绿
- [ ] `npm run build` 生成 `dist/`，`chrome://extensions` 加载无错误
- [ ] popup / options 无 console 异常
- [ ] 发布时打 tag 后 `npm run zip` 生成可安装 zip（日常构建不产出 zip）

## YouTube

- [ ] 手动字幕：双语同步，seek/全屏/剧场模式正常
- [ ] 自动字幕（ASR track）：可读取并翻译
- [ ] 直播：DOM 字幕兜底可出中文
- [ ] 广告：暂停翻译，广告结束恢复
- [ ] SPA 切换视频：重新抓取字幕，不残留旧 cue
- [ ] 原生字幕隐藏/恢复
- [ ] timedtext 403 时自动退到 DOM，不空白

## 通用视频

- [ ] HTML5 TextTrack：预取 + 同步
- [ ] 无字幕：音频链路 P50 ≤ 6 s，原声不断
- [ ] 静音/无音轨：提示未检测到音频
- [ ] 多视频：选择最大播放视频
- [ ] iframe：帧选举，覆盖层只出现一次
- [ ] 全屏：覆盖层重挂载
- [ ] 画中画：提示不显示

## Provider / 降级

- [ ] OpenCode Go 有效 key：翻译正常，`x-opencode-session` 已发送
- [ ] 缺 key：跳过云端，走本地/提示
- [ ] 400 policy：自动换 provider；无整段空白
- [ ] 429/500/超时：冷却、重试、最终原文
- [ ] 同视频 3 次拒绝：切 local-first 并提示
- [ ] 全部失败：原文 + “未翻译”
- [ ] Ollama 未启动：明确提示 `OLLAMA_ORIGINS`
- [ ] local-asr 未启动：明确提示 `node server.mjs`

## 生命周期

- [ ] 停止：track 释放、原声恢复、覆盖层移除、offscreen 关闭
- [ ] 关闭 tab：会话清理
- [ ] 刷新页面：旧会话停止或干净恢复
- [ ] SW 手动终止：offscreen 重连/停止，不卡死
- [ ] 30–60 分钟连续：内存增长 < 100 MB

## 权限/隐私

- [ ] 安装无 `<all_urls>` 内容脚本警告
- [ ] 自定义服务域名只在保存时申请权限
- [ ] 拒绝权限：设置不保存并提示
- [ ] Key 不出现在内容脚本/日志
- [ ] 清空缓存生效
- [ ] 首次使用需勾选隐私同意

## 性能

- [ ] 云端字幕模式 1080p CPU 增量 < 15%
- [ ] 1 小时视频无 OOM
- [ ] 本地 ASR RTF 记录；> 0.8 时给出建议
- [ ] 延迟埋点 P50/P95 记录
